# Bank Marketing Campaign Analysis

This project analyzes a bank marketing campaign dataset and organizes the raw data, cleaned data, Tableau dashboard, and documentation in a reproducible folder structure.

## Project Structure

```text
bank-marketing-analysis/
├── data/
│   ├── raw/
│   │   └── bank_marketing_raw.csv
│   └── cleaned/
│       └── bank_marketing_cleaned.csv
├── dashboard/
│   └── bank_marketing_dashboard.twb
├── docs/
│   └── cleaning_steps.md
└── README.md
```

## Files

- `data/raw/bank_marketing_raw.csv`: Original dataset.
- `data/cleaned/bank_marketing_cleaned.csv`: Cleaned dataset used for analysis and dashboarding.
- `dashboard/bank_marketing_dashboard.twb`: Tableau workbook for the dashboard.
- `docs/cleaning_steps.md`: Notes describing the cleaning workflow.
